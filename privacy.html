BotBros Privacy Policy

Effective 21 October 2026.

What BotBros is

BotBros is a private assistant system operated by Frank Gardner for his own family. It is not offered to the public. The only Google accounts that connect to it belong to members of that family, each of whom gives consent personally.

What data it accesses

With the account owner's consent, BotBros may read and write Google Drive files, Google Docs, Sheets, Slides and Forms, Gmail messages, Calendar events, Contacts, Tasks, YouTube library data, and photos selected by the owner. It accesses only the data of the account that granted consent, and only to carry out that owner's instructions.

How data is stored and used

Data is processed on computers owned and controlled by the family. Access tokens are stored on those computers in files readable only by the assistant that holds them. Google data is not copied to third-party services, is not sold, is not used for advertising, and is not used to train any model.

Sharing

BotBros does not share Google user data with any third party. Information leaves the family's own systems only when the account owner explicitly instructs the assistant to send it, for example by asking it to send an email.

Retention and deletion

Working copies of data are kept only as long as a task needs them. An account owner can revoke BotBros at any time in the Google account's third-party access settings, which immediately invalidates the stored tokens. On request, any retained copy of that owner's data is deleted.

Google API Services User Data Policy

BotBros' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
