BotBros

A private family assistant system run by Frank Gardner.

BotBros is a set of personal AI assistants that help one family manage its own documents, mail, calendars and files. It is not a public service and has no users outside the family that operates it.

The assistants connect to Google services only with the explicit consent of the account owner, read and write only that account's own data, and act on the owner's instructions.
